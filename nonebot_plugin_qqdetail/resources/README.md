# 字体资源

以下字体以原始名称与原始文件随插件分发，均采用 SIL Open Font License 1.1：

- `NotoSansCJKsc-Regular.otf`：来自 [Noto CJK](https://github.com/notofonts/noto-cjk)，用于简体中文与普通文本；许可证见 `NotoSansCJK-LICENSE.txt`。
- `NotoEmoji.ttf`：来自 [Google Fonts Noto Emoji](https://github.com/google/fonts/tree/main/ofl/notoemoji)，原文件名为 `NotoEmoji[wght].ttf`，用于矢量 Emoji；许可证见 `NotoEmoji-LICENSE.txt`。

字体内容未修改。卡片无需依赖操作系统字体或浏览器，Emoji 使用单色矢量字形。
